# Clip 转写与说话人分区测试报告

**Clip 上传后的默认服务器流程选 Qwen 0.6B + Nemotron 3。** 三条完整录音合计约 19 分 24 秒，Qwen 组合约 5 分钟出稿，MOSS 0.9B 约 19 分钟。两套流程平均都用了约 4 个逻辑核，Qwen 的累计 CPU 时间约为 MOSS 的四分之一。遇到分句或说话人归属拿不准的录音，可以用 MOSS 生成第二份稿子，和原音频一起核听。

- [Clip 真实录音](#clip-真实录音)：实际上传的完整录音，比较耗时、CPU 和两份输出的差异。
- [公开测试数据](#公开测试数据)：AISHELL-4 和 AliMeeting 共 11 段，用于横向比较模型，按人工参考的覆盖范围计算 cpCER 和 DER。
- [测试环境与指标](#测试环境与指标)：硬件、计时范围及表中指标的含义。

## Clip 真实录音

### Clip 默认选型

3 条上传录音共 1164.18 秒，最长一条 1147.18 秒。两套流程在同一台服务器上串行处理完整录音。

| 流程 | 完整流程秒 | 平均进程 CPU | 累计 CPU 秒 | 实时倍数 |
| --- | ---: | ---: | ---: | ---: |
| Qwen 0.6B + Nemotron 3 | 303.60 | 398.2% | 1208.80 | 3.83 |
| MOSS 0.9B | 1137.98 | 399.5% | 4546.36 | 1.02 |

### 最长一条录音的断句和分区

Qwen 输出 259 行，中位行跨度为 3.55 秒。MOSS 输出 235 行，中位跨度为 2.01 秒，但最长一行有 34.07 秒。把两份转写对齐到相同字符后，有 117 处同时加了句末标点。长行和两份稿子断法不同的地方可以优先听校。

Nemotron 3 对整条录音分区，用满了 8 个标签槽位。MOSS 用最长 180 秒的窗口，相邻窗口重叠 15 秒。拼接后有 17 个标签，其中 13 个缺少足够的跨窗接续证据。两边都检出语音的时间内，按时间重合做最佳匿名配对后，至少一个标签同时活跃的比例为 51.6%。

Clip 组缺少人工文字、句界和说话人标注。行长和标签差异用于定位复核，暂时无法判断哪份稿子的断句或说话人归属更准。

### Clip 录音效果

对服务器识别使用的三条 WAV 做信号检查。文件均为 16 kHz、16-bit 单声道。

| 指标 | 两条短录音 | 最长录音 |
| --- | ---: | ---: |
| 波形峰值（dBFS） | −13.2 至 −0.2 | 约 0 |
| 全段平均电平（RMS，dBFS） | −32.4 至 −31.3 | −34.8 |
| 达到 PCM 量程端点的采样数 | 0 | 2 / 18,354,880 |
| 低于 −50 dBFS 的 20 ms 帧占比 | 50.8%–65.1% | 44.1% |
| 模型输出 | 七套均保留主要内容 | Qwen 0.6B 与 MOSS 文字差异 18.4%（971 / 5285） |

0 dBFS 为数字满量程。低电平帧包含停顿，帧占比不能用来估算噪声。18.4% 为两份转写的字符编辑距离除以较长稿的字符数，用于定位听校。

**结论：** 这批 Clip 录音未见持续触顶，短录音的主要内容能稳定转出。长录音整体电平较低，且有接近满量程的峰值。会议纪要可先用 Qwen 组合出稿，专有名词、数字和多人交接处仍需回听。当前三条录音不足以判断远场清晰度、底噪或多人重叠时的拾音效果。

## 测试环境与指标

公开数据于 2026-11-06 在 Apple M5 Pro（15 个逻辑 CPU）上测试，于 2026-11-08 在 Intel Xeon Platinum 8488C（可见 8 个逻辑 CPU）上测试。两端均使用 4 个计算线程和 1 个调度线程，流程串行执行。

- **完整流程耗时**是识别、适用的标点、对齐和分区阶段的墙钟时间之和。加载、热身和写结果另计。实时倍数为音频秒数除以完整流程秒数。
- **累计 CPU 秒**是各线程的用户态和内核态 CPU 时间之和。平均进程 CPU 为累计 CPU 秒除以流程墙钟秒，再乘 100%。100% 对应平均占用 1 个逻辑核。
- **ASR 峰值 RSS**是服务器约每两秒采样得到的进程驻留内存峰值，包含模型加载。1 GiB 等于 1,073,741,824 字节。
- **cpCER**衡量转写与说话人归属的联合错误。匿名说话人做最优配对后，用字符插入、删除和替换数之和除以参考字符数。文字评分只用 AISHELL-4 的 5 段、53 个参考区间和 1071 个规范化字符。MOSS 的 96 ÷ 1071 约为 8.96%。
- **DER**用漏检、误报和说话人混淆的说话人秒之和除以参考说话人秒。本轮按最优匿名配对计分，计入重叠说话，边界宽容为 0 秒。两人同时说话一秒计作两个说话人秒。
